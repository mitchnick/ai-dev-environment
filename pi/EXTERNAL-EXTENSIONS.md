# External extensions

Configured npm packages:

- `@pi-plugins/usage`
- `pi-paster`
- `pi-claude-code-ui`
- `pi-web-access`
- `context-mode`
- `pi-subagents`
- `@juicesharp/rpiv-ask-user-question`
- `@juicesharp/rpiv-todo`
- `pi-autoresearch@1.6.2`

`extensions/package.json` and `package-lock.json` preserve the extension runtime dependencies and overrides.
